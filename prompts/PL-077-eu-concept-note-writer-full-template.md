# PL-077 - EU Concept Note Writer (Full Template)

> First stage of any EU grant application — concept note submission before full proposal. High-stakes entry point. Covers cover page summary, description of action (max 2 pages), and relevance (max 3 pages).

## Prompt

```text
Draft a complete EU concept note for the following action.

Project basics:
- Action title: [ACTION TITLE]
- Lead applicant: [ORGANISATION NAME], [COUNTRY]
- Co-applicants (if any): [LIST]
- Call for proposals: [CALL REFERENCE]
- Donor: [CERV / IPA / EIDHR / Erasmus+ / other EU instrument]
- Requested contribution: EUR [AMOUNT]
- Duration: [MONTHS]
- Target country/region: [COUNTRY / REGION, e.g. Western Balkans / North Macedonia]

Thematic focus: [HUMAN RIGHTS / GENDER EQUALITY / CIVIL SOCIETY / RULE OF LAW / DEMOCRATIC GOVERNANCE / other]

---

SECTION 1.1 — SUMMARY TABLE (no page limit)

Objectives:
- Overall objective (Impact): [WHAT LONG-TERM CHANGE DOES THE ACTION CONTRIBUTE TO?]
- Specific objective(s) (Outcome): [WHAT DIRECT CHANGE WILL THE ACTION ACHIEVE IN THE TARGET GROUP?]

Target groups: [WHO DIRECTLY BENEFITS FROM PROJECT ACTIVITIES?]
Final beneficiaries: [WHO BENEFITS INDIRECTLY IN THE LONG TERM?]
Expected outputs / Results: [LIST KEY DELIVERABLES AND OUTPUTS]
Main activities / Work Packages: [LIST ACTIVITY CLUSTERS]

---

SECTION 1.2 — DESCRIPTION OF THE ACTION (max 2 pages, Arial 10, single spacing, 2cm margins)

Draft the following subsections in order:
i. Background and context — sector/country/regional context, key challenges, any analysis informing design
ii. Objectives — explain the overall and specific objectives from Section 1.1
iii. Key stakeholder groups — their attitudes, any consultations held
iv. Intervention logic — expected outputs, outcomes, impact, main risks and assumptions
v. Type of activities — description and linkages between activity clusters
vi. Cross-cutting issues — how the action mainstreams: human rights, gender equality, democracy, good governance, youth, children’s rights, environmental sustainability (include only those relevant)
vii. Timeframe — broad timeline and any specific scheduling factors

Tone: formal, evidence-based, results-oriented. Avoid passive voice. Use EU PCM terminology throughout.

---

SECTION 1.3 — RELEVANCE OF THE ACTION (max 3 pages, same format)

1.3.1 Relevance to call objectives:
i. Relevance to the objective(s) and priority(ies) of the call
ii. Relevance to specific subthemes / sectors / areas and requirements (including local ownership)
iii. Which expected results from the call guidelines will be addressed

1.3.2 Relevance to target country/region needs:
i. Specific pre-project situation with quantified data where possible
ii. Detailed problem analysis — how problems are interrelated at all levels
iii. Relevant national/regional/local plans and how the action relates to them
iv. If continuation of a previous action: how it builds on previous results
v. If part of a larger programme: fit, coordination, synergies (especially with EC)
vi. Complementarity with EU and other donor initiatives — avoid duplication

1.3.3 Target groups and beneficiaries:
i. Description of each group (quantified where possible) including selection criteria
ii. Needs and constraints of each group
iii. Relevance of the proposal to those needs
iv. Participatory process ensuring their involvement

1.3.4 Added value:
Any specific added-value elements — public-private partnerships, innovation, best practice, multiplier effect

---

Quality rules:
- Strictly respect page limits (2 pages for 1.2, 3 pages for 1.3)
- Each section must be in proportion to its evaluation weight (see call evaluation grid)
- Full information — evaluation is based solely on what is provided
- Clear, direct language to facilitate evaluation
- Reference [CALL REFERENCE] throughout where relevant
```

## Example Output

Complete EU concept note: cover table (objectives, target groups, outputs, activities), 2-page action description, 3-page relevance section — donor-compliant, results-oriented, Western Balkans context
