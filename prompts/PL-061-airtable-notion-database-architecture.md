## Prompt

```text
Design a [Airtable / Notion] database for [USE CASE: grants CRM / M&E tracker / project management / beneficiary registry / donor pipeline].

Organisation type: [CSO / NGO / Consultancy]
Users: [NUMBER AND ROLES]
Key processes: [LIST 3-5]
Integrations: [Google Drive / Slack / Zapier / Make / n8n / manual]

Deliver:
1. Table/database schema: name, purpose, key fields, field types (text/number/select/relation/formula)
2. Relationships between tables (linked records)
3. 3-5 recommended views per table (grid, gallery, kanban, calendar, form)
4. Automation suggestions (trigger → action)
5. Rollup and formula field examples for key metrics
6. Onboarding checklist for team (5 steps)

Favor lean, maintainable structures. No over-engineering.
```

## Example Output

Database schema with table names, field definitions, relationships, view recommendations, automation logic, and team onboarding guide
