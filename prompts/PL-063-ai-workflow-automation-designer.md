## Prompt

```text
Design an AI workflow automation for [USE CASE / RECURRING TASK].

Current manual process: [STEPS, TOOLS, TIME SPENT]
Desired outcome: [WHAT SHOULD BE AUTOMATED AND WHY]
Available tools: [n8n / Make / Zapier / Airtable / Notion / Google Workspace / Slack / Claude API]
Constraints: [BUDGET / TECHNICAL SKILL / NO-CODE PREFERENCE / DATA PRIVACY]

Deliver:
1. Automation blueprint (trigger → AI processing → output → destination)
2. Tool stack recommendation with rationale
3. Implementation sequence (ordered by dependency)
4. Estimated time saving per month
5. Risk flags (data quality, human-in-the-loop, cost limits)
6. Priority matrix: Quick wins / Medium-term / Strategic

Favor lean no-code first. Optimize for fast experimentation and usability.
```

## Example Output

Automation blueprint: trigger → AI step → output → destination, with tool stack, time saving estimate, and implementation priority matrix
