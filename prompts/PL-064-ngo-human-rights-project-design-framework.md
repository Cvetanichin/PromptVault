## Prompt

```text
Design [/ Review and improve] a civil society project for [ORGANISATION] in [COUNTRY/REGION].

Problem area: [HUMAN RIGHTS ISSUE / THEMATIC FOCUS]
Target population: [BENEFICIARIES AND RIGHTS-HOLDERS]
Funding context: [DONOR IF KNOWN, e.g. EU CERV / EIDHR / bilateral]
Duration: [MONTHS]

Deliver:
1. Problem analysis (root causes, contributing factors, systemic barriers)
2. Theory of Change (if…then logic, key assumptions, change pathway)
3. Logframe skeleton (Overall Objective → Specific Objectives → Outputs → Activities)
4. Implementation approach (direct delivery / capacity building / advocacy / litigation / research)
5. Partnership structure (lead, implementing partners, target groups, duty-bearers)
6. Cross-cutting considerations (gender, inclusion, do-no-harm, safeguarding)
7. Key risks and mitigation

Apply results-based management. Flag any logical gaps directly.
```

## Example Output

Full project architecture: problem analysis, ToC, logframe skeleton, implementation approach, partnership structure, and risk mitigation
