## Prompt

```text
Design a [FULL PROGRAMME / SINGLE MODULE] on [TOPIC] for [TARGET GROUP].

If FULL PROGRAMME ([X]-day):
- Learning objectives (max 5)
- Session breakdown with timings, facilitation methods, and materials per session
- Pre/post assessment approach
- Participant feedback form template
- Apply non-formal education principles

If SINGLE MODULE:
- Module learning objectives
- Content sections with teaching methods (lecture, group work, case studies, role play)
- Materials needed and time allocation per section
- Assessment approach (quiz, reflection, peer review)
- Facilitator notes

Output as structured table.
Context: [ORGANISATION TYPE / THEMATIC AREA]
Audience level: [BEGINNER / INTERMEDIATE / ADVANCED]
```

## Example Output

Full programme table with objectives, timings, methods, materials, and assessment OR single-session module outline
