## Prompt

```text
Create a visual impact map for [PROJECT/PROGRAMME NAME] for [REPORTING PERIOD].

Programme data:
- Overall goal: [IMPACT STATEMENT]
- Outputs achieved: [LIST WITH NUMBERS]
- Outcomes with indicators: [LIST WITH BASELINE → ACTUAL]
- Beneficiaries reached: [NUMBERS BY CATEGORY]
- Geographic coverage: [REGIONS/LOCATIONS]

Visual format: [IMPACT TREE / RESULTS CHAIN / INFOGRAPHIC / DASHBOARD CARD]
Destination: [Canva / PDF report / HTML dashboard / PowerPoint]
Color palette: Deep Blue #1E3A52, Green #5B8A5A, Gold #D6B04D, Ivory #F7F4ED

Include: hierarchy (Activities → Impact), key numbers prominently displayed, one headline pull-quote, geographic reach indicator.
Output: structured layout description with exact text content ready to drop into Canva or HTML.
```

## Example Output

Visual results chain: Activities → Outputs → Outcomes → Impact, with beneficiary counts, geographic reach, and headline achievement
