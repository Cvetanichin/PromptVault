## Prompt

```text
Write a [COLD INTRODUCTION / FOLLOW-UP / COVER NOTE / THANK YOU] email to [DONOR/FUNDER NAME] from [ORGANISATION NAME].

Donor context: [FOCUS AREAS, RECENT GRANTS, PROGRAMME OFFICER NAME IF KNOWN]
Organisation profile: [MISSION, KEY ACHIEVEMENT, RELEVANT TRACK RECORD]
Ask: [MEETING / CONCEPT NOTE REVIEW / FULL PROPOSAL / ACKNOWLEDGEMENT]

Tone: professional, warm, evidence-grounded. Not generic. Max 220 words.
Structure: (1) Hook — specific reference to donor’s work, (2) Why us — one concrete achievement with numbers, (3) The ask — one clear action, (4) Close.

Avoid: ‘We are pleased to’, ‘We hope this finds you’. Lead with value.
```

## Example Output

Personalised 200-word email with clear value proposition, specific donor alignment reference, and one concrete ask
