## Prompt

```text
Turn this rough idea into a testable MVP specification:

[DESCRIBE YOUR IDEA IN 2-3 SENTENCES]

Target users: [WHO WILL USE THIS AND WHAT PROBLEM DOES IT SOLVE]
Constraints: [BUDGET / TIMELINE / TECHNICAL SKILL / PREFERRED TOOLS]
Priority: [SPEED / QUALITY / LEARNING]

Deliver:
1. Problem statement (crisp, 1 sentence)
2. Core user flow (step-by-step, from first action to value moment)
3. Feature set: Core (must ship) | Stretch (v2) | Out of scope
4. Database structure: entities, key fields, relationships
5. UI copy: key screens with exact text for buttons, labels, empty states
6. Prompt flows (if AI-powered): trigger → input → Claude prompt → output → destination
7. Build sequence: what to build first, second, third
8. Handoff notes: what a developer or no-code builder needs to start immediately

Favor lean no-code. Optimize for fast experimentation and clarity.
```

## Example Output

Full build spec: problem statement, user flows, feature set (core vs stretch), database schema, UI copy, prompt flows, and handoff-ready implementation notes
